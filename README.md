# Of Ambition and Grind — Email Signature Banner

Standalone browser-based generator for a 600×200 px email-signature banner.

## Run locally
Open `index.html` in a browser. For GIF export, if the browser blocks local worker loading, use GitHub Pages or any simple static HTTP server.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

The generator uses the source image in `assets/book-background.png` and can also accept another image through the file picker.

No backend, Google Drive, Apps Script, or book author's domain is required.
